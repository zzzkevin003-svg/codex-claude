# Codex 执行说明 · 《请按门铃》第一集直接开拍

**原则：一口气跑完，中途只停两次等人。** 测试阶段到此结束，有问题就只返工出问题的那个镜头。

## 0. 先收尾（不用停）
1. 把本机还没提交的测试结果移进仓库对应目录，然后 commit、push：
   - `qing-an-men-ling-tests/retest-v2/` → `剧集/请按门铃/测试/林夏人物一致性/第二轮/重测/`
   - `qing-an-men-ling-tests/s04-s05-720p/` → `剧集/请按门铃/测试/S04-S05试拍/`
2. 把画布上第一集的 8 镜分镜写成 `剧集/请按门铃/E01/镜头清单.md`，沿用 `模板/镜头清单.md` 的格式。每个镜头写清楚景别、机位、动作、时长、声音、和上下镜头怎么衔接。S04 已有成片，直接标"已完成"。

## 1. 出全部关键帧（不用停）
- 每个镜头出**首帧**；需要和下一个镜头动作衔接的，再出**末帧**（沿用 S04 的首尾帧做法）。
- 每张出 2 张候选，最多重抽 1 次，还不行就在清单里标 `需人工`，接着做下一个镜头。
- 拼一张总览图 `E01/关键帧总览.jpg`：每个镜头一行，候选标成 A / B。

### 已验证可行的做法（照着用）
| 情况 | 做法 |
|---|---|
| 所有含林夏的镜头 | 连接人物主参考图 `i-m6EiiCNBMx`；侧脸镜头再加 04 v2 作为辅助参考 |
| 控制景别 | 用画面边界和百分比写清楚头顶、鞋底的位置。模型通常会比目标偏大约 10%，所以目标要写小一点 |
| 同一场景只换光线或时间 | 以已选定的帧为底图**做编辑**，不要从零重新生成 |
| 相邻镜头动作衔接 | 用上一镜的末帧做下一镜的首帧（可以裁切或编辑） |
| 转身、侧脸 | 写明"肩、胸口和脸一起转向画面左/右侧，视线看向镜头外" |

## ⏸ 停顿 1：人工挑关键帧
在聊天里发总览图，等创作者一次性回复，例如 `S01-A S02-B S03-重做…`。只重做被点名的镜头，重做后不需要再停。

## 2. 出全部视频（不用停）
- Seedance 2.5，720p，16:9，用首尾帧（或只用首帧）生成。时长按清单来，最短 4 秒。有对白或门铃声的镜头按清单开启声音。
- 每个镜头最多抽 2 次，选更好的一条，另一条也保留。
- 取**无水印交付**版（1280×720，24fps），存到 `E01/video/S0X.mp4`。

**预算上限：本集 3,000 积分**（视频约每秒 46 积分；55 秒约 2,530，再留一些重抽的余量）。累计花费超过 2,500 时，先停下来报告。

## 3. 粗剪（不用停）
用本机的 ffmpeg 按顺序把 8 个镜头拼接成 `E01/粗剪_v1.mp4`。只做硬切；声音保留模型生成的，暂不配乐、不加字幕。

## ⏸ 停顿 2：人工看粗剪
提交并推送所有文件，回报以下内容：粗剪路径、每个镜头的抽卡次数和积分、总积分、剩余余额、有哪些镜头标了 `需人工`。
