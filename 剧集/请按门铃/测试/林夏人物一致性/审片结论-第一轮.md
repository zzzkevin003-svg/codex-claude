# 林夏人物一致性 · 第一轮审片结论（Claude，2026-11-23）

审片对象：主参考图 v1、7 张 Seedream 5.5 静帧、2 条 Seedance 2.5 样片。两条视频各抽首帧、中间帧、尾帧。
打分：脸 / 发型 / 服装，每项 1–5 分（5 = 和参考图一模一样，3 = 能认出来但有明显差异）。待两位创作者复核签收。

## 结论

1. **身份一致性基本过关。** 能看清脸的镜头都在 4 分以上，"同一张参考图 + Seedream 5.5 / Seedance 2.5"这条路线可以继续用。
2. **真正的问题是构图和角度不听话。** 只写"人物占画面四到五成"、"转 45°"这类描述，模型不照做，常常会自动拉成全身居中，或者让人物回头看镜头。这会直接影响分镜能不能拍出来。
3. **参考图只有一张正面。** 侧脸、背影、低头这些角度靠模型自己猜。《请按门铃》有门口、猫眼之类的侧面镜头，需要补侧面参考图。
4. **交付的文件带"AI生成"水印**，视频也只有 480p 样片。正式镜头需要确认无水印导出和 720p 以上的积分成本。
5. 视频是直接用参考图（灰背景）来动的，还没测过"在剧情场景里的关键帧做图生视频"。
