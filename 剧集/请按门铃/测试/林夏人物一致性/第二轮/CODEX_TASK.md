# Codex 执行说明 · 林夏一致性第二轮

背景见 [审片结论-第一轮](../审片结论-第一轮.md)。目标只有三个：把构图和角度控制住、补齐参考图、在剧情场景里试一次图生视频。

## 规则（和第一轮相同）
- 提示词**逐字原样**提交，不改写。`{{Node i-m6EiiCNBMx}}` 指第一轮的主参考图节点。
- 生图模型固定用 `doubao-seedream-5-5`，16:9，2K；每项出 **2 张**，方便比较稳定性。
- 结果存到本目录的 `stills/`、`reference/`、`video/` 下，命名为 `编号_try1.png`、`编号_try2.png` 等；把提示词、节点、任务编号、积分追加到本目录的 `生成记录.json`。
- **每一步做完都停下**，等人审核后再进行下一步。

## 第 1 步：补测（构图控制）

构图写法改成**用画面边界和具体比例来描述**，并加上"不要什么"。

**R2-02 远景**
> 使用 {{Node i-m6EiiCNBMx}} 作为唯一人物身份参考，生成真人写实短剧静帧。画面只有林夏一人，保留参考图的脸型、眼形、眉形、偏分齐肩黑发和深灰圆领上衣，下身素黑直筒长裤。远景：相机在约6米外平视，林夏站在画面中央偏右，从头顶到鞋底只占画面高度的40%，人物上方和左右留出大片空墙与地面。空旷朴素的住宅室内玄关，暖灰墙面，明亮柔和的自然日光从画面左侧进入。不要拉近，不要让人物占满画面，不要美颜，无文字、拼贴或边框。

**R2-04 3/4 侧（45°）**
> 使用 {{Node i-m6EiiCNBMx}} 作为唯一人物身份参考，生成真人写实短剧静帧。画面只有林夏一人，保留参考图的脸型、眼形、眉形、偏分齐肩黑发和深灰圆领上衣。腰部以上的中景。林夏的头和身体一起转向画面左侧约45度，鼻尖指向画面左边缘，视线看向画面左侧的门，不看镜头；能看到她的右耳，左边脸颊被轻微遮挡。空旷朴素的住宅室内玄关，暖灰墙面，柔和自然日光从画面左前方照来。不要回头看镜头，不要美颜，无文字、拼贴或边框。

**R2-06 夜景暖光（单变量：改用编辑方式）**
不再从零生成，而是**以第一轮的 01-baseline 为底图做图像编辑**，只改光线，保证构图不变：
> 保持这张图的人物、构图、景别、机位、姿势和服装完全不变，只改变光照：改为夜晚，室内只开一盏位于画面左侧墙上的暖黄壁灯（约2700K），人物脸部左侧被暖光照亮、右侧落入阴影，背景墙面变暗。脸部五官必须清晰可辨。不要改变人物的脸、发型或衣服，不要加入其他人物或文字。

如果 LibTV 不支持图像编辑，就改用 Seedream 生成，把 01 和主参考图都作为参考图，提示词不变，并在记录里注明。

## 第 3 步：剧情场景图生视频（S04 → S05 门把衔接）

使用分镜里 S04、S05 的现有提示词，**同时连接主参考图和第 2 步选定的参考图**：
1. 先用 Seedream 出 S04、S05 的关键帧，每个 2 张，**停下等人选定**。
2. 选定后，用 Seedance 2.5 做图生视频，**用 720p 正式档，不用样片模式**，每条 5 秒。
3. 在生成记录里写清楚：每条视频消耗的积分、是否带水印、无水印导出需要什么条件。这些数据用来算单集成本。
