# AI短剧协作

供两位创作者使用 Codex 与 libtv 协作制作 AI 短剧的项目空间。

## 项目目标

从创意和剧本出发，逐步打通素材准备、libtv 制作、审核迭代与成片归档流程。

## 建议协作约定

- 每集建立独立文件夹，保留剧本、镜头清单、生成素材和版本记录。
- 在 Codex 中共同维护流程文档与文本资产；将大体积视频素材留在 libtv 或约定的共享存储中。
- 每次交接写明当前版本、已完成事项和下一步负责人。
- 不在项目文件中保存账号密码、访问令牌等凭据。

## 目录

- `流程/`：工作流、工具连接与协作约定
- `剧集/`：各集剧本和制作资料
- `模板/`：可复用的剧本及镜头模板
