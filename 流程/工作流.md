# AI 短剧制作工作流（初稿）

1. **策划**：明确题材、受众、单集时长、集数与发布平台。
2. **剧本**：在 Codex 中共创梗概、分集大纲、对白和镜头清单；双方确认后标记版本。
3. **制作准备**：整理角色设定、场景、视觉风格、参考图及镜头提示词。
4. **libtv 制作**：将确认后的素材与提示词提交 libtv；记录任务链接、素材位置、参数和结果版本。
5. **审核迭代**：按镜头检查角色一致性、画面连续性、对白、节奏与音画；问题回写到镜头清单。
6. **成片归档**：保存最终成片位置、字幕/封面、版本号和发布状态。
